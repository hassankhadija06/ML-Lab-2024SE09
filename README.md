## Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/ML-Lab-2024-SE-09.git
   cd ML-Lab-2024-SE-09
   ```
2. Install Jupyter and the libraries used so far:
   ```bash
   pip install notebook numpy matplotlib
   ```
3. Open any lab notebook:
   ```bash
   jupyter notebook Lab_02/Lab02.ipynb
   ```

Lab 01 needs only Python. Lab 02 needs NumPy, plus matplotlib for one optional plot. Later labs may need more libraries (for example pandas or scikit-learn); each lab's README lists what it needs.
